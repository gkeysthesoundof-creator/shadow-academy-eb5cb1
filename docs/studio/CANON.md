## Canon Update 03 — Fable-first development

Gerald has substantial unused Fable usage and has authorized a Fable-first development strategy
for Romans World. This overrides earlier model-selection instructions in the project kit.

- Primary development model: Fable 5.2, or the latest Fable version available on Gerald's account.
- Default thinking effort for architecture and major development: High.
- Studio Director: Fable.
- Use Fable for complex engineering, gameplay implementation, creative craftsmanship,
  educational systems and architectural decisions.
- Reserve Opus for independent reviews, difficult debugging and safety evaluations.
- Reserve Sonnet for routine maintenance, minor changes and straightforward content implementation.
- Specialist agents should inherit the session model unless their assigned task explicitly
  requires another model.

Prioritize craftsmanship, reliability, maintainability, child-friendly design and extensibility
over minimizing model usage alone.

Do not interpret increased model availability as permission to expand project scope, activate
unnecessary agents, skip testing or bypass approval gates.

Preserve all Seven Laws, private content separation, Source Fidelity and Parsing Integrity
requirements, Work Order discipline and existing Prompt Haus infrastructure.
