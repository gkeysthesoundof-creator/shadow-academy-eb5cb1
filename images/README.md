# Roman's character pictures

Drop any two pictures you own into this folder and the game shows them on the home screen automatically:

- `hero.png` — appears on the left (Roman's hero)
- `villain.png` — appears on the right (the rival)

Any picture works: a drawing Roman made, a photo of Roman in costume, or artwork from your own collection. If a file is missing, the game simply shows nothing there. No other steps needed.
